You are updating the system memory after one application cycle.

Inputs:
- data/applications.md
- knowledge/master-profile.md
- knowledge/application-learnings.md
- The latest application context (job, resume variant, cover letter, outcome)

Goal:
Convert one application outcome into durable learning for future applications.

Process:
1) Capture what was submitted:
   - role/company
   - resume version used
   - cover letter angle used
2) Capture response signals:
   - recruiter response speed
   - feedback snippets
   - interview outcome stage
3) Classify signals:
   - strengths validated
   - objections raised
   - unknowns still blocking progress
4) Update learning memory:
   - append or update entry in knowledge/application-learnings.md
   - add any durable insights to knowledge/master-profile.md
5) Recommend next iteration:
   - what to keep
   - what to change
   - which role archetypes to prioritize next

Output format:
- Application recap
- Signals learned
- Memory updates made
- Next iteration plan (max 5 bullets)
