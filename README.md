# Freelance Client Outreach Starter

This repository now contains a lightweight browser-based MVP for a freelance
client outreach system tailored to Mihir Botle's skill set:

- 3D explainer videos
- Architectural visualization
- Product renders
- Marketing content
- Small websites / interactive 3D showcases

## What this MVP does

- Recommends the best small-business client segments to target first
- Shows practical lead-source searches for each segment
- Maintains a simple in-browser lead board
- Generates tailored outreach messaging:
  - cold email
  - DM / short message
  - call opener
  - discovery questions
  - follow-up guidance
- Explains how this can evolve into a more automated client-finding system

## Why this direction

Based on the resume and portfolio references, the strongest positioning is not
"general 3D artist for everyone." The better fit is:

> Technical 3D artist who can help small businesses explain, visualize, and
> market products, spaces, and concepts without needing an in-house 3D team.

That positioning fits smaller companies such as:

- boutique architecture and interior firms
- furniture and home decor brands
- jewelry brands
- industrial machine manufacturers
- real-estate developers
- marketing agencies that need a 3D execution partner

## Run locally

No build step is required. Open `index.html` in a browser.
